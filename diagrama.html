📊 Diagrama de Funcionamento - JustDelivery

🔄 Fluxo Principal do Sistema

1. Criação do Ticket

Usuário preenche formulário com dados do pedido

2. Validação e Processamento

Sistema valida dados e calcula valor total

3. Armazenamento

Ticket salvo no LocalStorage com ID único

4. Renderização

Ticket exibido na interface com status "Pendente"
